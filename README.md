## Overview

**Samarohh** is a modern celebration and event companion designed to streamline multi-day weddings, corporate galas, and cultural summits. It eliminates messy spreadsheets and disorganized group chats with an elegant, friction-free mobile web experience.

---

## Key Capabilities

* **Frictionless Guest RSVPs:** Guests confirm attendance, specify plus-ones, and note dietary preferences in seconds—without needing to create passwords or download native apps.
* **Segmented Ceremony Schedules:** Attendees access personalized event itineraries tailored to the specific functions they are invited to attend.
* **Interactive Venue Guides:** Embedded navigation, venue locations, dress codes, and event timing keep guests informed in real time.
* **Real-Time Host Dashboard:** Event organizers track confirmed headcounts, dietary requirements, and guest travel details instantly.
* **Instant Delivery:** Deliver invites and timely schedule reminders directly to guests via WhatsApp and web.
